The base paper is about overlapping communities, but until now I had only scored disjoint labels. So I scored Stage 3 against real overlapping ground truth from the SNAP datasets. On Amazon, 81 percent of nodes truly belong to several communities but Stage 3 with the paper's default flags only 4 percent, and the gain in agreement is small. On DBLP the truth has only 15 percent overlap but Stage 3 flags 25 percent and agreement drops below the plain disjoint output. So the overlap rate is not adapted to the graph. Also, EQ, the metric the paper uses for overlap, decreases as I add overlap on Amazon even though agreement with the truth increases, so EQ alone is a weak guide. This is a finding about the paper, not yet a fix.
