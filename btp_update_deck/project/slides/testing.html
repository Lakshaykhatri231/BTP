How I tested the changes

Set 1

Development

8 classic real graphs, Amazon Photo, and LFR graphs (n=1000, noise 0.3 to 0.7, 5 seeds each). Used to design the changes.

Set 2

Held-out

72 synthetic graphs made afterwards (new seeds, n up to 10,000, coarse and small communities), plus Amazon Computers, Coauthor-CS and Coauthor-Physics.

Set 3

Fresh

Cora-ML, Pubmed and DBLP-authors, fetched last and used only to validate.

Rules fixed in advance: paired multi-seed comparison, NMI and modularity reported together, and a change becomes default only if no held-out real graph loses more than 0.005 NMI.

BTP progress update · Label propagation for community detection

8

Most label propagation papers test on a handful of small graphs, where one node moving changes the score a lot. I used three separate sets so that I could not fool myself. The development set is where I designed the changes. The held-out set was generated afterwards and never used for design. The fresh set was fetched last, only to validate. I fixed an adoption rule before looking at the held-out results: a change only becomes the default if no unseen real graph loses more than 0.005 NMI. Several of my own changes failed that rule, and I kept them optional.
