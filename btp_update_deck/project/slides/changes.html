Five changes, all opt-in. With every switch off the code gives exactly the paper's results; I verified this by hashing the outputs before and after each edit. The first two are from Phase 3, the last three from Phase 4. The size-corrected Stage 2 is the key one: it subtracts what a random graph with the same degrees would give, which bounds the rich-get-richer effect. The paper's Eq. 12 is the special case where that correction is zero. The granularity rule decides when to trust the size-corrected version. The merge pass fixes the under-merging on sparse graphs.
